# Data and font notices

Map, routing, and geocoding data is derived from OpenStreetMap and is made available under the Open Database License
(ODbL): <https://www.openstreetmap.org/copyright>. User interfaces must visibly display
`© OpenStreetMap contributors`.

Font bundles are deployment artifacts, not repository files. Every bundle must include `LICENSES.json` recording
the exact Noto font source, version, file checksum, and license. Noto fonts are distributed under the SIL Open Font
License; operators must preserve the included license files and provenance.

Tilemaker artifacts record checksums for OSM-derived water polygons (ODbL 1.0) and Natural Earth public-domain
landcover inputs. Preserve their generated `LICENSES.json` provenance with every archived data release.
